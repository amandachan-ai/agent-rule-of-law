# Agent Rule of Law (ARL) v0.1

**Governing delegation in coding agents with five separated powers: problem definition, framework, and a preregistered experiment design.**

📖 **[Read the document](https://amandachan-ai.github.io/agent-rule-of-law/)**

## Status

**Experiment design registered; no evidence yet.** This version does not claim that ARL works. The preregistered experiment (Section 4) will be run and reported under the decision rules written in the document, including unfavorable and inconclusive results.

## In one paragraph

When a coding agent spawns sub-agents, the same agent often decides what to do, who does it, what counts as done, and whether it was done well. ARL names this *Unchecked Delegation* and defines four measurable failure modes: self-certification, privilege creep, false completion, and rule decay. It separates five accountability functions (Legislative, Executive, Judicial, Examination, Control), keeps goals, the constitution, and scoring criteria in an external anchor the system cannot write to, and preregisters an experiment that separates the effect of separation of powers from the effect of extra compute.
